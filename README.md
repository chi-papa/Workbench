# Workbench
​A minimalist, ivory-toned single-file HTML workbench and link launcher with grid layout, category filtering, favorites, and dark mode support.


余白とグリッド設計を重視した、ゼロ依存・単一HTMLファイルのパーソナルリンクランチャーです。  
自作ツール、制作向け素材サイト、ジェネレータ、各種マニュアルをひとつの画面から素早く呼び出せます。

## 主な特徴

* **余白を活かしたグリッドUI**  
  情報を詰め込みすぎず、視認性と操作性を両立したレスポンシブなカードグリッドを採用しています。
* **アイボリー基調 ＋ ダークモード切替**  
  目に優しい紙のようなアイボリー（`#f6f4ee`）をデフォルトテーマとし、右上のボタンからダークモードへ瞬時に切り替えられます（設定はブラウザに自動保存）。
* **カテゴリ＆サブカテゴリ絞り込み**  
  「自作ツール」「素材サイト」「ジェネレータ」「マニュアル」の4つの主要タブに加え、「素材サイト」内ではジャンル別（写真・イラスト・アイコン・配色・CSSなど）に絞り込めます。
* **お気に入り（★）の先頭固定**  
  各カードの `☆` をクリックするとお気に入り登録され、各カテゴリの先頭および `★` フィルタに自動で集約されます（`localStorage` に保存）。
* **完全ゼロ依存・単一ファイル**  
  外部ライブラリやビルド環境は一切不要。`WorkbenchWeb.html` をブラウザで開くだけ、または GitHub Pages に置くだけですぐに動作します。

## 収録カテゴリ

| タブ | 内容 | 件数 |
| :--- | :--- | :---: |
| **自作ツール** | 業務・制作向けの自作Webツール群（見積書、配送追跡、運賃・価格シミュレーターなど） | 8 |
| **素材サイト** | 写真・イラスト・SVG・配色・CSSアニメーション・UI・音素材などの厳選リンク | 54 |
| **ジェネレータ** | テーブルレイアウト、Flexbox、ローカル画像圧縮などの補助ツール | 3 |
| **マニュアル** | 機器設定や業務手順のガイドページ | 2 |

## 使い方

1. `WorkbenchWeb.html` をブラウザで開きます（または GitHub Pages 等に公開してアクセスします）。
2. 上部のタブからカテゴリを選択します。
3. よく使うリンクの右上にある `☆` をクリックすると `★` になり、一覧の先頭に固定されます。
4. 右上の月／太陽アイコンで、アイボリー／ダークのテーマを切り替えられます。

## カスタマイズ方法（リンクの追加・編集）

HTMLファイル内の `<script>` にある配列 `D` に1行追加するだけでリンクを増やせます。

外部リンク先のコンテンツおよび利用規約は、各サイトの運営元に帰属します
